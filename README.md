# pepper-lang.dev

The website at <https://pepper-lang.dev>: plain HTML and one stylesheet, served by GitHub Pages from `main`. The book is a separate site, <https://docs.pepper-lang.dev>, built from [pep-lang/pepper](https://github.com/pep-lang/pepper).

Pages link to the book's newest release (`/0.10.0/`); move those links when a release comes out. Each release also gets a line in `blog/index.html`.

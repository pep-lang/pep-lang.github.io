Install Pepper

Each release publishes the toolchain prebuilt for Linux, macOS and Windows, with an install script that downloads the right one. You need no LLVM install to use it.

Linux and macOS

curl -fsSL https://raw.githubusercontent.com/pep-lang/pepper/main/scripts/install.sh | sh

Windows (PowerShell)

irm https://raw.githubusercontent.com/pep-lang/pepper/main/scripts/install.ps1 | iex

The script puts the toolchain in ~/.pepper (%LOCALAPPDATA%\pepper on Windows), adds it to your PATH, and builds and runs a small program to check the install. The book's Installing Pepper chapter covers every option and what the script changes.
